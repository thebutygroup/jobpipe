{% comment %} Tag-chip input widget (Chunk 5, pulled forward 13 Aug at Joe's request). Dependency-free, single include. Usage: add data-tagchips="1" to any text input whose value is a comma-separated list; optionally data-suggest="/url" for type-ahead (endpoint returns a JSON array of strings for ?q=). Contract: the ORIGINAL input keeps its name and carries the joined "A, B, C" string at all times — the server never knows chips exist. With JS off the include does nothing and the plain comma-separated input remains, so the form still submits fine. A11y: WAI-ARIA combobox pattern — role=combobox entry, role=listbox suggestions, aria-activedescendant virtual focus, Esc closes, and each chip's remove button is labelled "Remove ". {% endcomment %}
